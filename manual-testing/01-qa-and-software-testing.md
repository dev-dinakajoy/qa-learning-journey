# QA and Software Testing

## What I learned

Today I learned the difference between **QA** and **software testing**.

### Software Testing

Software testing is checking whether a software application behaves as expected and finding situations where it doesn't.

For example, on a login page I can test:

* Valid email + valid password
* Valid email + wrong password
* Empty email
* Empty password
* Invalid email format
* Multiple login attempts

### QA

QA is broader than testing.

Testing focuses heavily on finding problems in the product.

QA also focuses on improving the process used to build the product and preventing problems.

### The difference I understand

> **Testing:** Find problems in the software.

> **QA:** Help prevent and detect problems throughout the development process.

## What surprised me

I initially thought QA was mostly about clicking around an application looking for bugs.

I'm learning that a good QA tester has to understand requirements, think about risks, design tests, communicate clearly, and work closely with developers and product teams.

## Key takeaway

A QA tester shouldn't only ask:

> "Does it work?"

A better question is:

> "What should happen, what could go wrong, and how can I prove it?"
